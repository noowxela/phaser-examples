# Screenshots

Gallery card images, grouped like the game folders:

| Folder | Games |
|--------|--------|
| `ready/` | Published catalog (`games/ready/<name>/`) |
| `coming-soon/` | WIP (`games/coming-soon/<name>/`) |
| `dummy/` | Experiments (`games/dummy/<name>/`) |

Use the same basename as the game folder, e.g. `ready/run.jpg` for `games/ready/run/`.

`otherGame/` is legacy metadata for entries not in the main `games.js` list.
