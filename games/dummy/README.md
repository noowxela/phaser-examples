# Dummy games

Scratch / experiment demos that are not ready for the public gallery.

- Add folders here as `games/dummy/<slug>/` (same HTML + `js/game.js` layout as other games).
- Register each game in `games/games.js` with `name: 'dummy/<slug>'` and optional `isDummy: true` (or rely on the `dummy/` name prefix).
- They appear under the **Dummy** tab on the gallery; use **Admin mode** in the menu to open them locally.
